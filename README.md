Twin Views is an original spot-the-difference game that runs entirely in the browser from static files. Two hand-drawn pictures sit side by side across three rounds - a sunny seaside cafe, a forest cabin library at dusk, and a night lantern festival - with 22 differences to find against the clock. Found differences are ringed on both pictures, a big REMAINING counter tracks what is left, wrong clicks cost 5 seconds, and hints pulse at a hidden difference for 50 points. It plays with mouse or keyboard (arrow keys move a magnifier, Space checks the spot), with generated WebAudio sound effects and no network requests, images, or external assets: every scene is drawn with canvas shapes.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
# hand in the entry with: mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
